# Harness 展示设计

本文约束模型在线游玩与 `data/transcripts` 共用的玩家可见文本。目标是在不删除
决策事实的前提下减少内部 ID、重复字段和横向长句，使战略状态可以快速扫描。

## 基本原则

1. 玩家界面已有中文名称时只显示中文，不向模型暴露 Boss、角色、卡牌或附魔的
   英文资源 ID。稳定索引继续保留，因为动作参数依赖索引。
2. 同类对象统一使用一项一行的形式：
   `- [索引] 名称（费用与类型）〔动态状态〕：玩家可见效果`。
3. 卡牌名称末尾的 `+` 已代表升级，不再重复显示“升级等级1”。当前规则文本已经
   反映升级、附魔和永久数值变化，不再额外重复内部动态变量名。
4. 只展示当前版本、当前实例的真实玩家可见结果；不把内部枚举、资源路径、RNG 或
   隐藏信息放进 Harness。
5. 转录器继续调用与在线推理相同的 `system_prompt()` 和 `build_observation()`；旧 raw
   缺失的字段不推测补造。

## 整局上下文

Boss 只显示中文名；复合 Boss 继续显示成员：

```text
本幕Boss: 帝皇蟹 | 组成: 碾碎爪、火箭
```

进阶效果从横向长句改成逐行列表：

```text
难度5:
- 精英蜂拥：精英敌人出现更加频繁。
- 旅途劳顿：先古之民只会回复已损失生命值的80%。
```

药水栏与遗物使用相同的一项一行结构，空槽也保留索引：

```text
药水栏 3/5:
- [0] 敏捷药水：获得2点敏捷。
- [1] 火焰药水：造成20点伤害。
- [2] 空
- [3] 空
- [4] 空

遗物 2 件:
- [0] 破损核心：在每场战斗开始时，生成1个闪电充能球。
- [1] 羽翼之靴〔计数2〕：可无视路线前往任意相邻节点。
```

牌组按实例显示，但不重复英文 ID、升级等级和内部动态变量：

```text
牌组 2 张（升级1，附魔1）:
- [0] 打击+（1费攻击）：造成9点伤害。
- [1] 防御（1费技能）〔附魔：灵巧×2〕：获得7点格挡。
```

能量与星能费用必须同时保留，例如 `七星（2费+7星能攻击）`、
`星尘（0费+X星能技能）`；X 费不能被默认数字代替。

附魔优先使用 Mod 返回的中文标题；重建旧 v0.111.0 raw 时允许用同版本规范附魔
ID—中文名表恢复中文名称，但绝不把 `NIMBLE` 等英文 ID直接展示给模型。

## 卡牌候选

奖励、卡牌包、战略选牌、牌组浏览页和商店卡牌与牌组使用同一个卡牌行格式。升级
选择只展示升级后的结果，避免模型拿当前效果猜升级收益：

```text
=== 选择卡牌 ===
选择1张牌来升级。以下展示升级后效果：
- [0] 打击+（1费攻击）：造成9点伤害。
- [1] 冷静头脑+（1费技能）：生成1个冰霜充能球。抽2张牌。
```

战略 `deck_upgrade_select` 必须由 v0.111.0 游戏模型在独立卡牌副本上执行一次真实
升级，返回升级后的名称、费用、类型和解析规则文本；Harness
不维护卡牌升级表，也不根据卡牌 ID 猜数值。历史 raw 若没有保存该预览，转录必须
明确标记“旧录像未保存升级预览”，不能把升级前效果冒充升级后效果。

## 商店

商店卡牌、遗物和药水都使用“名称/属性—状态—效果”的逐行结构，价格与购买状态
放入统一状态括号：

```text
=== 商店（库存已打开）===
卡牌:
- [0] 球状闪电（1费攻击）〔75金币〕：造成7点伤害。生成1个闪电充能球。
遗物:
- [0] 数据磁盘〔150金币；金币不足〕：每场战斗开始时获得1点集中。
药水:
- [0] 火焰药水〔50金币〕：造成20点伤害。
删牌〔75金币；可用〕
```

已售出的空槽只显示 `- [索引] 已售出`。动作名称和参数仍只以末尾“可执行动作”为
准，展示格式变化不修改真实库存、索引、价格或动作域。

## 非目标

- 本轮不精简战斗手牌、敌人意图或牌堆信息；
- 不删除卡牌、药水和遗物的当前效果文本；
- 不修改地图、Proceed 例外、Recorder raw 或 Tree-GRPO 状态边界；
- 不为了缩短文本引入版本哈希、卡牌强度表或遗物 ID 特判。
